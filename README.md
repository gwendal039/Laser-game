# Laser Arena

Laser Arena is a browser-based arcade FPS built with HTML5, JavaScript and Three.js.  
The project is inspired by real-life laser tag arenas and fast-paced FPS games, with a focus on responsive movement, laser shooting, AI opponents, scoring, respawn systems and replayable game modes.

The current version includes Free For All and Team Battle modes, AI bots with variable difficulty, neon-style arena design, match scoring, player statistics, and the foundations for long-term progression, customization and daily objectives.
